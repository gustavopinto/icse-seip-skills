# Replication package: Careful with That Axe, Eugene

Replication package for the paper *Careful with That Axe, Eugene: Enterprise Agent Skills That Say One Thing yet Do Another*.

The study codes 502 LLM agent skills from the centrally governed AI skill catalog of a large enterprise and asks whether the delegation intent a skill's description communicates (assistive or executive) matches what its body encodes (shell command blocks and interaction mode). One skill in three is misaligned: 107 (21%) are over-declared and 66 (13%) are under-declared.

## What is included

The skills are proprietary, and we cannot release them. This package contains:

- the coding scheme (`codebook/dimensions.md`);
- the prompt used for LLM-assisted coding (`codebook/coding_prompt.md`);
- the patterns of the sensitive-program scan (`scripts/sensitive_scan.py`);
- the scripts that compute every number in the paper (`scripts/numbers.py`) and its figures;
- the per-skill labels and structural signals, under pseudonymous IDs (`data/labels.csv`, `data/sensitive_programs.csv`);
- the manual review of the autonomous labels (`data/autonomous_review.csv`);
- the per-model labels and agreement scripts of the re-coding (`data/recoding/`).

No name, description, or text of a skill is included.

## Layout

```
codebook/
  dimensions.md            coding scheme: D1–D7, matrix rule, signals, scan categories
  coding_prompt.md         system and user messages sent to the LLM
data/
  README.md                data dictionary
  labels.csv               502 skills: signals, coded labels, matrix cell
  sensitive_programs.csv   502 skills: sensitive programs and severity (RQ3)
  autonomous_review.csv    53 skills: manual review of the autonomous labels
  recoding/                re-coding with five other models (Table 2)
figures/                   figures of the paper, regenerated by the scripts
scripts/
  numbers.py               recomputes every number of the paper
  plot_results.py          Figures 2–5
  wordcount_hist.py        Figure 1
  apply_autonomous_review.py  applies the manual review to labels.csv
  sensitive_scan.py        sensitive-program scan (needs the skills)
  build_corpus.py          extraction and LLM coding (needs the catalog)
```

## Reproducing the results

Requires Python 3.10 or later.

```
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

python3 scripts/numbers.py                      # every number of the paper
python3 scripts/plot_results.py                 # figures/fig1_domain.pdf, ...
python3 scripts/wordcount_hist.py               # figures/fig_wordcount.pdf
```

`numbers.py` needs only the standard library. With `--tex path/to/main.tex`, it also checks each value against the macros the paper defines.

`data/labels.csv` already includes the manual review of the autonomous labels. `apply_autonomous_review.py` documents that step; running it again leaves the file unchanged.

### Steps that need the proprietary skills

`build_corpus.py` extracts the structural signals from the catalog packages and codes each skill through an OpenAI-compatible endpoint (`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`). `sensitive_scan.py` scans a directory of `SKILL.md` files. Neither can be run without the catalog; both are included so that the extraction rules, the prompt, and the scan patterns can be inspected and applied to other skill collections, such as public ones:

```
python3 scripts/sensitive_scan.py --skills path/to/skills --out scan.csv
```
